# Verification & Test Runner Skill

## Purpose
Executes comprehensive test suites, assertion verifications, and quality gates for applications.

## Guidelines
1. Discover and run unit, integration, and end-to-end tests using `pytest` or `unittest`.
2. Verify input/output contracts, service health responses, and persistence invariants.
3. Validate negative paths, timeout handling, and edge case assertions.
4. Output structured test reports with execution counts, timing, and pass/fail verdicts.
